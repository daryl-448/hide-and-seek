# Paper digests

These are condensed digests of the source papers, for replication and for synthesizing new ideas. The source PDFs are local only: they are git-ignored and will be deleted.

Each digest keeps equations and table values verbatim from the paper. It also flags errors and inconsistencies in the source paper under "Inconsistencies and gotchas".
